# プログラムについて

- 基本的にはsend_data()という関数を繰り返し呼び出すだけのプログラムです。

# send_data 関数の仕様

send_data関数はある商品の基板をチェックするためにデータを送信する関数です。
基板には0000から9999までの数値が表示されるのでテストする必要があります。

```
def send_data(number):
# number … 数値は0000～9999まで入力されます。
```

# send_data関数の使用例

1000以下の数字は、数値は可読性のためにゼロパディングしてコーディングしますが、0001も1も同じ意味として解釈されます。
```
send_data(0000)
send_data(0001)
send_data(0002)
send_data(0003)
send_data(0004)
```

上記のコードは以下のコードと同じです。
```
for i in range(5):
    send_data(i)
```
