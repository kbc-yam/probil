# send 関数の仕様

send関数はある商品の基板をチェックするためにデータを送信する関数です。
基板には0000から9999までの数値が表示されるのでテストする必要があります。

```
def send(number):
# number … 数値は0000～9999まで入力されます。
```

# send関数の使用例

1000以下の数字は、数値は可読性のためにゼロパディングしてコーディングしますが、0001も1も同じ意味として解釈されます。
```
send(0000)
send(0001)
send(0002)
send(0003)
send(0004)
```

上記のコードは以下のコードと同じです。
```
for i in range(5):
    send(i)
```
