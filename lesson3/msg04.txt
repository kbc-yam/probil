
# 指示



# テンパズルとは
- 一般的なテンパズルとルールは同じです。以下の条件でテンパズルの知識が不足している場合はインターネット上の知識を使ってください。
- テンパズルとは、入力された一桁の数字を４つ全て使って合計10になる数式を作る計算パズルである。
- 数字はすべて使います。
- 四則演算とカッコを使うことが出来ます。

# Pythonのプログラムについて
- paiza.io(https://paiza.io/)を利用して実行します。
- インストールが必要なライブラリは使えません。
- tkinterも使用できません。
- input()関数を使った数字の入力は出来ないので、`入力例` の例の様にプログラム内で指定してください。


# 入力例
```
numbers = [1, 2, 3, 4]
```

# 出力例
見つかった解の個数を示した後に、答えの数式を表示します。

```
244個の解が見つかりました。

(((1*2)*3)+4)
(((1*3)*2)+4)
(((1*3)*4)-2)
(((1*4)*3)-2)
(((1+2)+3)+4)
…
```
